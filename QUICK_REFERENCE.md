## 🔧 Configuration

Open Settings (`Cmd/Ctrl+,`) and search "Jarvis" to adjust:

- `jarvis.autoPilot` - Toggle automatic mode (default: true)
- `jarvis.autoFixOnSave` - Fix on save (default: true)
- `jarvis.analysisInterval` - Update frequency (default: 2000ms)
- `jarvis.maxAutofixPerFile` - Maximum fixes per file (default: 50)

## 📞 Troubleshooting

### Extension Not Showing
- Check Extensions panel: `Cmd/Ctrl+Shift+X`
- Search "Jarvis"
- Should see "Jarvis - Premium AI Coding Assistant"

### Auto-Pilot Not Working
- Reload VS Code: `Cmd/Ctrl+R`
- Check settings: Is `jarvis.autoPilot` enabled?
- View Output: View → Output → Select "Jarvis"

### Backend Not Responding
- Check it's running: `curl http://localhost:8001/`
- Port 8001 should be in use
- Check process: `ps aux | grep app.py`

### Slow Performance
- Increase analysis interval: Set to 5000ms
- Disable real-time: Set `realTimeAnalysis` to false
- Reduce max fixes: Set `maxAutofixPerFile` to 10
